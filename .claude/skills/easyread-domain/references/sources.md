# 표준 근거와 출처 (Provenance)

이 문서는 easyread-domain의 원칙·규칙이 **어떤 표준 제정 기관·전문 기관 자료에 근거하는지**를 기록한다.
규칙 자체의 단일 소스는 [validation-checklist.md](validation-checklist.md)이며, 이 문서는 그 규칙들의 **근거·출처**를 다룬다.

프로젝트 데이터(지침 리소스, 단어 사전)는 아래 자료를 **저작권 확인 후 자체 요약·재구성**해 만든다. 원문 전재는 하지 않는다(NFR-04). 각 사전·지침 항목의 `source` 필드에 아래 서지정보를 기재한다.

> 확인 시점: 2026-08-09. URL·판본은 개정될 수 있으므로 데이터 적재(WBS T-06) 시점에 재확인한다.

## 4. 표준에는 있으나 v0.1 자동 규칙에 없는 항목 (backlog)

전문 표준이 다루지만 현재 규칙 엔진에 자동 규칙으로 넣지 않은 항목. 도입 시 ADR-03 절차(체크리스트 → rules-config → 코드 → 골든 테스트)를 따른다. 상세는 [validation-checklist.md](validation-checklist.md) 말미 "규칙 후보".

| 표준 항목 | 근거 | 현재 처리 | 도입 조건 |
|---|---|---|---|
| 같은 대상은 늘 같은 낱말로(용어 일관성) | IE #9 | guidelines §2에 원칙만 | 동의어/개념 사전 확보 시 보조 규칙(VOC-07 후보) |
| 독자에게 직접 말하기('여러분', '~하세요') | IE #15 | guidelines §1·프롬프트 | 한국어 경어체 특성상 자동화 난이도 높음 → 프롬프트 지시로 유지 |
| 부정문보다 긍정문(단순부정 포함) | IE #16 | SEN-04는 이중부정만 자동 | 단순부정 선호는 오탐 큼 → 보조/info 후보 |
| 일상생활 예시로 설명 | IE #8 | guidelines §2·프롬프트 | 규칙 아님(생성 지시) |
| 중요한 정보는 반복해도 됨 | IE #20 | 프롬프트·오탐 방지 참고 | 규칙 아님(SEN-05/STR 오탐 방지 기준으로 반영) |

## 5. 저작권·검증 메모

- 위 자료 중 다수는 저작권이 있다. 데이터화는 **원칙의 자체 재구성**만 하며 문장·표를 그대로 옮기지 않는다.
- Inclusion Europe 표준은 CC 계열로 널리 재사용되나, 로고·삽화는 별도다. 국내 정부·기관 자료는 공공누리 유형을 항목별로 확인한다.
- 사전 대체어의 1차 권위는 국립국어원(표준국어대사전·다듬은 말)로 두고, 항목별 `source`에 근거를 남긴다.
