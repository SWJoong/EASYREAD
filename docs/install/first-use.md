어려운 공지문을 한 토막 준비합니다. 예시로 아래 문장을 씁니다.

## 2. 쉬운 정보로 바꿔 달라고 합니다

Claude에게 이렇게 부탁합니다.

> 이 글을 발달장애인도 이해하기 쉬운 정보로 바꿔줘: (위 문장 붙여넣기)

- `simplify-text` 프롬프트를 고르면 더 정확합니다.
- Claude가 짧은 문장·쉬운 낱말로 **초안**을 만들어 줍니다.
  - 예: “못 올 사정이 있으면, 다른 사람이 대신 서류를 낼 수 있어요.”

## 3. 검사합니다

바뀐 글이 규칙에 맞는지 검사합니다.

> 이 초안을 validate_easy_read로 검사해줘. 원문도 같이 볼게: (원문 붙여넣기)

**검사 결과 읽는 법**

- **verdict**: `ok`면 통과, `needs-review`면 고칠 곳이 있다는 뜻입니다.
- **규칙 ID**: 어떤 규칙에 걸렸는지 알려줍니다(예: `SEN-01` 문장이 길다, `VOC-01` 어려운 낱말).
- **심각도**: `error`(꼭 고치기) → `warning`(고치면 좋음) → `info`(참고).
- **가장 중요한 것은 정확성(ACC)입니다.** 날짜·금액·기관명·연락처가 바뀌면 안 됩니다. 원문과 함께 검사하면 이걸 잡아 줍니다. **ACC `error`는 0건이어야 합니다.**

## 4. 고칩니다

검사가 가리키는 문장을 다듬고, 다시 3번으로 검사합니다.
`error`가 없어질 때까지 반복합니다.

## 5. “감수 전 초안”임을 꼭 기억합니다

이 도구가 만든 결과는 **감수를 거치지 않은 초안**입니다.
도구는 감수를 대신하지 않습니다.
마지막에는 **발달장애인 당사자의 확인·감수**를 거쳐 최종본을 정합니다.

## 이 서버가 검사하는 것 (규칙 6가지)

- **문장(SEN)**: 한 문장에 한 가지 정보, 짧게.
- **어휘(VOC)**: 어려운 말·전문용어·줄임말을 쉬운 말로.
- **숫자(NUM)**: 아라비아 숫자, 정확한 날짜, 큰 수는 감이 오게.
- **구성(STR)**: 중요한 것 먼저, 나열은 목록으로.
- **표기(TYP)**: 기호(※, ~, &)는 말로 풀어서.
- **정확성(ACC)**: 원문의 사실을 바꾸거나 빠뜨리지 않기.

## 자주 막히는 곳

1. **도구가 안 보여요.** Claude Desktop은 앱을 완전히 껐다 켭니다. Claude Code는 `claude mcp list`로 `easyread`가 있는지 봅니다.
2. **Node 버전이요.** 터미널에 `node -v`를 칩니다. 숫자가 22보다 작으면 새로 설치합니다.
3. **인터넷이요.** 검사할 때는 인터넷이 필요 없습니다. 설치할 때만 필요합니다.
